# forgelane

Forge color lane values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/forgelane/

## Install / run

```bash
git clone https://github.com/theworker02/forgelane.git
cd forgelane
node src/cli.js
node --test
```
